Отметки и часы хранятся на этом устройстве. Чтобы они совпадали на телефоне и ПК, настройте вкладку «Синхр.».

Честно: путь B1 → 7.5 в среднем требует 900–1200 часов осмысленной практики. 18 месяцев по 10–15 часов в неделю — это реально, но только при регулярности. Пропуск недели лучше компенсировать короткими занятиями, чем «наверстывать» в выходные.

Как выглядит неделя

  • Пн–Пт: 1.5–2 ч в день. Одно «тяжёлое» занятие (грамматика или writing, 45–60 мин) + одно лёгкое (listening, чтение, Anki).
  • Суббота: 2–3 ч. Речь с репетитором или записью себя + проверка письменных работ.
  • Воскресенье: 2–3 ч. Таймированный тест или его часть, затем разбор ошибок. Это самое важное занятие недели.
  • Каждый день, 15 минут: Anki (повторение слов). Не пропускайте, иначе очередь вырастет.

Методы, которые дают результат

  • Журнал ошибок. Каждая ошибка из тестов и эссе — в таблицу: что, почему, правильный вариант. Раз в неделю перечитывать.
  • Диктант (Listening). Короткий отрывок 1–2 мин: слушаете, пишете, сверяете с транскриптом. Затем shadowing — повтор вслух вместе с диктором.
  • Интервальные повторения. 8–10 новых слов в день в Anki, только с примером предложения и коллокациями, а не одиночные слова.
  • Запись речи. Отвечаете на вопрос Part 2 на 2 минуты, записываете, слушаете, переписываете слабые фразы, записываете снова.
  • Writing с обратной связью. Эссе без проверки почти не растёт. Нужен репетитор или Write & Improve, плюс переписывание по замечаниям.
  • Тесты по таймеру. С фазы 2 всегда с таймером и без пауз; целиком — раз в неделю в фазе 4.
  • Метод «разобрать, потом перепройти». После теста выяснить, почему ответ неверный, и только потом идти дальше.

Основные материалы

  • Cambridge IELTS 10–19 (официальные тесты) — главный источник для проверки уровня и тренировок. Начинать с 10–13, свежие 17–19 оставить на фазу 4.
  • The Official Cambridge Guide to IELTS — формат, стратегии, задания по каждому навыку.
  • Британский совет и IDP — бесплатные пробные материалы и информация о регистрации.

Грамматика

  • Murphy, English Grammar in Use (Intermediate) → Advanced Grammar in Use.
  • Cambridge Dictionary (онлайн) для проверки примеров.

Словарь

  • Academic Vocabulary in Use и Collins Vocabulary for IELTS для фазы 3.
  • Anki — карточки с примерами предложений.

Listening

  • BBC Learning English: 6 Minute English (фаза 1–2).
  • TED и TED-Ed с транскриптами; подкасты BBC и ABC (Australia) для разных акцентов.
  • Тесты Cambridge IELTS — секции 1–4.

Reading

  • Фаза 1: graded readers уровня B1–B2, BBC News Learning English.
  • Фаза 2–3: BBC News, The Guardian, The Economist, Scientific American, Aeon.
  • Тесты Cambridge IELTS по таймеру.

Speaking

  • Репетитор на italki или Preply: 1 раз в неделю в фазе 1–2, 1–2 раза в неделю в фазе 3–4.
  • Запись на телефон (самопроверка), приложение ELSA Speak для произношения.
  • Банки вопросов Part 1–3 из Cambridge IELTS и открытые подборки тем.

Writing

  • Write & Improve (Cambridge) — бесплатная обратная связь по уровню.
  • Репетитор или преподаватель IELTS для оценки по четырём критериям.
  • Разборы эссе band 7+ на ielts-simon.com и ieltsliz.com.

Синхронизация телефон ↔ ПК

Отметки и часы отправляются в вашу личную базу Firebase (бесплатно) и подтягиваются на других устройствах. Один и тот же адрес и код нужно ввести на каждом устройстве.

Настройка Firebase (один раз, 5 минут)

  1. Откройте console.firebase.google.com, войдите через Google и создайте проект (Google Analytics можно отключить).
  2. В меню слева: Build → Realtime Database → Create Database. Регион любой, режим «locked».
  3. Откройте вкладку Rules, вставьте правила ниже и нажмите Publish.
  4. На вкладке Data скопируйте адрес вверху (начинается с https://) и вставьте сюда в «Адрес базы».
  5. Нажмите «Создать код», затем «Синхронизировать». Адрес и код введите так же на втором устройстве.
{"rules":{"ielts":{"$code":{".read":true,".write":true}}}}

Данные доступны только тому, кто знает ваш код, поэтому не показывайте его другим. Внутри только галочки и число часов.
