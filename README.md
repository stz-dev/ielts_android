# IELTS 7.5 — трекер (Android)

1. Создайте аккаунт на github.com и новый репозиторий (New repository, имя любое, Public или Private).
2. Загрузите в него ВСЕ файлы из этого архива (Add file → Upload files). Папку .github тоже.
3. Откройте вкладку Actions. Сборка запустится сама (или нажмите Build APK → Run workflow).
4. Через 3–6 минут откройте завершённый запуск и скачайте артефакт ielts-plan-apk (внутри app-debug.apk).
5. Перенесите APK на телефон, откройте его и разрешите установку из неизвестных источников.
